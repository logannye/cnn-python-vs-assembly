# Readable repository mirror

The [complete measured bundle](https://github.com/logannye/simple-cnn/releases/download/baseline-cifar10-assembly-25-v1/cifar10-assembly-25-v1.tar.gz) contains the executable, initializations, augmentation schedules, checkpoints, probabilities and all retained audits. The [private release](https://github.com/logannye/simple-cnn/releases/tag/baseline-cifar10-assembly-25-v1) retains its archive checksum and primary audit.

This mirror includes readable text, JSON and figures. Links to omitted binary files point to the complete archive. `bundle-checksums.json` describes original bundle bytes; it does not describe rewritten Markdown in this mirror. `checksums.json` describes the files actually present in this mirror (excluding itself). The frozen source snapshot in the archive is the authoritative source evidence.
